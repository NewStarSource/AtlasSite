# 星图隐私、数据与公共 API 政策 v2.2

## 1. 账户与公开身份

星图只接受新星账户登录。新星账户可用邮箱注册；星图用户可以使用化名，也可以拥有多个账户。

账户化名允许修改，但公开保留改名记录。用户主页默认公开当前化名、公开改名记录、加入或关注的社群、担任过的代表身份；个人介绍沿用新星账户。

用户可以逐个将加入或关注关系设为私密，也可一键隐藏全部。代表身份必须公开。用户之间不提供普通关注关系；只能关注社群和主题。

星图不单独设置年龄门槛，沿用新星账户的年龄设置，不因年龄额外限制星图功能。

## 2. 浏览、搜索与通知

未登录访客可浏览星图全部公开页面，只有注册账户才能发布、互动、加入社群、申请入口或参与治理。

星图不允许任何公开内容被外部搜索引擎收录。站内搜索可以搜索社群名称、主题标签、社群介绍、公开动态、讨论、活动、创作、用户化名和公开代表身份；不搜索隐藏关系、申请材料或行为数据。

默认开启的通知为社群动态、社群活动和对自己参与讨论的回复。一般状态变化和非本人事务的代表更替默认关闭；与本人有关的申请决定、处罚申诉、投票结果和安全事务必须站内通知。通知默认在站内显示；用户可选择邮箱通知和每日汇总。

## 3. 收集、使用与保存的数据

星图只保留运行所需的：

- 登录与安全日志；
- 页面访问和站内搜索记录；
- 内容互动记录；
- 用户手动设置的推荐权重。

访问、搜索和普通安全日志保存 30 天，搜索原词不写日志，仅保存必要脱敏记录。点赞、收藏、加入和屏蔽等功能状态保存至用户撤回或注销，不因日志到期而消失。推荐权重保存至用户修改或注销。用户可撤回功能状态、删除草稿并导出仍被保存的本人数据；安全日志在明确期限内受限保存。所有类别的保存期限、争议冻结和备份处理统一见 TECH-11 生命周期表。

星图不允许第三方统计、广告或追踪服务参与。非公开行为数据仅限少数技术与安全人员按权限访问；社群代表只能查看本社群的汇总数据，不能查看成员个人行为。

## 4. 推荐与注意力控制

推荐权重由用户自行设置，可覆盖兴趣主题、具体社群、内容类型、单个用户、熟悉与探索比例、新旧内容比例等。

浏览、点赞、收藏和加入等行为可以提出权重调整建议，但必须由用户确认后才生效。星图不在用户不知情时自动改变其推荐权重。

## 5. 站内申请与私密资料

面向私密社群的站内申请，默认只必填加入原因；昵称、联系方式与自我介绍可选。申请办结后，星图和社群受限区域保留 7 天；发生争议时才延长，争议结束后删除。

成员资格证明只对新星团队可见，核验完成后 7 天删除。

涉及多人社群内部材料，必须取得全部可识别当事人同意；无法取得完整同意时，仅在彻底匿名化后才可发布。Wiki 私下核验也只保留必要结论，原始材料在核验完成后 7 天删除；如有明确争议，按 TECH-11 限时冻结并复核，不作为长期平台档案。

## 6. 数据导出、注销与内容状态

用户可导出平台仍保存的本人内容、关系、推荐设置、通知、本人申请和最终选票、账户与改名历史。导出不恢复已到期清理的数据，也不包含他人身份、他人选票、举报人信息、原始举报证据、内部风控规则或关联账户映射；混合记录只导出经脱敏的本人部分。

账户注销时，用户可以选择哪些内容删除、哪些内容保留。保留内容继续显示原化名，并标记“已注销”；不再链接到可登录账户。社群介绍、代表声明等公共信息继续保留版本记录。

## 7. 公共 API

星图提供供所有用户使用的公共数据 API。API 只提供：

- 社群页面；
- 兴趣主题；
- 社群关系；
- 公开活动；
- 公开帖子及其作者化名、已注销状态；
- Wiki 公开页面、版本历史、关系和公开脚注，范围以 SA6 为准。

API 不提供用户主页、加入/关注关系、申请材料、行为日志、内部治理材料或其他非公开数据。

API 返回内容许可证、发布时间、编辑状态和删除状态；调用方必须遵守相应许可证。API 使用 API 密钥、频率限制和滥用封禁。

公共 API 不得用于建立站外镜像、站外搜索索引或推荐站，也不得绕过星图内部的发现、隐私和内容边界。

## 8. 平台透明

星图持续公开：捐赠收支、规则与代码变更、内容处理与申诉统计、社群与活跃趋势、推荐规则与更新、安全事件。具体处理公开依据、条款与结果，但匿名化当事人。

普通成员提案的联署名单、关联主体及撤回轨迹不公开，只展示必要汇总；本人可查看、撤回和导出仍保存的本人联署。公开实施台账记录已接受公共职责的实施人、交付日和进展，不附私密证据。独立复核人员只依据 SA2 第 5.1 节的逐案授权访问必要卷宗；任职身份公开不表示获准读取全部原件，个人同意和法定限制仍然适用。相关数据期限见 TECH-11。

## 9. 外部访问和内容授权

网站为可索引的 HTML 和文件响应设置 `X-Robots-Tag: noindex, nofollow`，HTML 同时声明 noindex；robots.txt 标明抓取规则。公开页面可以被人阅读，这些信号只约束遵守规则的爬虫，不构成访问控制或不被复制的保证。受限内容必须通过服务端权限校验；禁止把 robots.txt 当作保护私密资料的措施。

首版不开放全站 RSS、公开批量镜像和官方站外存档服务。API 用于个人阅读工具、辅助访问和获授权的局部研究；客户端默认缓存不超过 24 小时，使用前验证最新可见性，收到删除或限制通知后清理缓存。违规抓取按暂停密钥、通知原因和允许申诉的流程处理。

API 访问条件与内容版权分开。CC BY/CC BY-SA 已经授予的合法复制和改编权利不会因平台禁抓、撤回或注销而撤销；不将禁止镜像表述为 CC 许可证的附加限制。保留全部权利的内容不授权站外再发布；作者发布前必须能看见许可证选择和这一差异。

短期核验资料、举报附件和临时导出不进入长期备份；普通数据库备份最长保留 12 个月，仅用于灾难恢复，恢复后先重放删除记录再开放访问。具体例外和期限见 TECH-11。
