# 星图 2026.10 发行笔记

记录时间为 2026 年 10 月 31 日，覆盖星图 AtlasSite 与新星账户 StarAccount 的十月开发。星图本月完成了内容社区的基础功能，加入团队与社群代表管理，并完成服务器部署。

项目接下来暂不公测，继续内部使用和验证。本月已部署的程序继续作为后续开发的基础，公测时间另行决定。

## 本月交付

### 登录与账户

星图通过新星账户登录，账户服务独立保存密码。注册使用一次性邀请码，支持会话查看与撤销、敏感操作重新验证身份，以及两端账户状态同步。

新星账户增加一次性恢复码。新注册账户可保存恢复码，已有账户可验证密码后生成或替换；忘记密码时可以使用恢复码设置新密码，旧会话随之失效。恢复已注销账户与忘记密码分别处理。

个人资料支持 Markdown 编辑和预览，星图可以展示账户资料。星图内保留个人动态、回复、收藏和订阅入口。

### 社群与内容

社群目录支持领域、方向和细分分类，提供社群介绍、接触方式、主题及待分类入口。公告、新人指引和讨论合集可以浏览。

内容功能已支持文字动态、多层回复、图片和 Markdown。作者可以保存草稿、修改与删除自己的内容，关联或解除关联社群与主题。读者可以点赞、收藏及订阅社群或主题。

站内搜索覆盖社群、主题、公开动态和用户化名。首页、社群动态、个人内容、收藏、搜索和通知加入分页，避免只显示固定数量的内容。

### 隐私与个人权利

用户可以屏蔽其他用户、一键隐藏全部社群关系，设置回复通知，导出仍被保存的本人数据，并在注销时选择内容保留方式。删除、隐藏、解除关联和恢复流程已有相应的权限检查与回归测试。

举报、紧急请求和申诉已提供用户侧入口及处理状态。运营侧已有受限处理命令，网页管理台尚未包含完整案件工作台。

### 团队与社群代表

管理面板增加社群、团队、代表和操作记录页面。团队管理员可以登记、续期和撤销授权，团队成员可以维护社群基础资料。社群代表仅能维护自己获得有效授权的社群。

授权包含依据和到期时间。修改需要验证身份，旧版本提交会被拒绝；操作记录可以查看变更前后内容，并保护最后一位有效管理员。

当前管理台支持维护社群名称、简介和联系说明。代表登记属于授权记录管理，成员资格、代表选举和定期投票确认尚未实现。

### 界面与使用体验

前端按 SAfiles 的 HTML 参考调整，统一黑白样式、表单、内容排版与移动布局，并减少页面上的说明文字。

各页面右上角增加搜索和更多图标浮层。帮助、状态等辅助入口收进更多，首页移除多余导航，详情页的关联管理也收进浮层。点赞和收藏使用图标与状态反馈，成功操作不再反复显示提示文字。

操作按钮统一高度，表单失败时保留输入并显示错误。账户资料的 Markdown 编辑与预览也纳入现有页面。

### 部署与运行

两个服务增加生产 HTTPS 支持，提供 Ubuntu、systemd 和 Caddy 部署配置，配套备份、监控、发布构建和版本校验脚本。发布产物可以记录两个仓库的提交及文件校验值。

项目已部署到服务器。当前数据库版本为星图 7、新星账户 6。代码包含加密备份、恢复、维护和只读模式；外部告警接收与异机恢复仍需落实实际目的地和演练。

## 验证记录与边界

十月提交中保留了单元、HTTP、迁移、权限与前端交互测试，以及生产 HTTPS、恢复码和发布检查脚本。仓库 README 记录了本地与服务器验收结果，涉及 Go 测试、静态检查、漏洞扫描、双服务联调及浏览器检查。

本笔记依据提交记录、当前代码和已有验收记录编写，编写时未重新连接服务器核对运行版本，也未重跑全部验收。它不代表已完成持续运行指标、压测或全部 SA 规范的验收。
