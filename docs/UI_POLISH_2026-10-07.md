# 界面与常用操作完善（2026-10-07）

按用户确认的三个方向改进现有界面，沿用 SAfiles 的黑白设计和简短文案。

## 已实现

- 账户统一使用 SAfiles 标志、系统字体、46 px 输入框、44 px 操作按钮、圆角、焦点和间距。移除原有大边框表单容器，登录页收窄，资料页使用适合编辑的宽度。CSS 改为内嵌在二进制中的同源资源，CSP 不再允许内联样式。
- 账户导航按登录状态显示入口，并标出当前页面。登录、注册失败在原表单显示简短结果，保留输入，提交期间防止重复操作。成功后进入账户首页；无 JavaScript 时沿用服务器页面返回。
- 内容列表统一头像、作者、社群、时间和标题层次；摘要最多三行，长文本可换行。悬停不再移动内容位置。时间保留完整日期提示和标准 datetime。
- 登录用户可以直接在列表收藏。列表收藏、详情收藏/点赞、社群/主题页订阅原地更新按钮状态与简短反馈；计数采用服务端结果。失败保持最后确认的状态，提交期间禁用按钮，取消后可再次操作。
- 资料校验返回明确字段，在对应输入附近显示错误并定位焦点；编辑时清除该字段错误。保存失败不覆盖数据库，网络失败使用简短中文提示。Markdown 编辑与预览保持可用。
- 表单保持真实 action、目标状态、登录与 CSRF 校验，禁用 JavaScript 时仍可提交。没有增加数据库迁移、外部服务或产品功能范围。
