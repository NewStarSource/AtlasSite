# 管理面板

入口 `/admin`，有有效团队或社群代表授权的用户可从任意页面右上角“更多”进入。
沿用 SAfiles 的黑白样式、现有导航、搜索浮层与移动布局。添加和编辑授权默认折叠，保持页面简洁。

## 功能与权限

| 身份 | 可用功能 |
| --- | --- |
| 团队管理员 | 维护全部社群资料；登记、修改、续期和撤销团队与代表授权；查看管理记录 |
| 团队成员 | 维护全部社群资料；查看团队、代表和管理记录；不能授予权限 |
| 社群代表 | 维护自己有有效授权且正常开放的社群资料；查看自己的代表授权及对应社群的资料变更记录 |
| 普通用户、访客 | 无管理台访问权限 |

社群资料支持名称、简介、联系说明，保存后直接反映在公开社群页面。来源核验、社群状态、他人动态及举报原件不属于本面板编辑范围。

团队授权最长一年，代表授权最长六个月，每个社群一个代表席位。登记必须填写授权依据（公开授权记录链接或编号），到期即时失效。撤销保留版本记录，防止旧表单在重新授权后覆盖新授权。普通注册和社群创建不会自动成为管理员或代表。

此功能维护已有授权记录，未实现成员资格认定、秘密选举、投票确认或独立复核人员抽取。管理员技术权限不等同于正式治理资格；代表登记不能代替 SA2 所需的成员授权程序。

## 首位管理员

使用已有星图用户 ID 或唯一化名，通过本地命令初始化：

```powershell
go run ./cmd/staratlas admin-bootstrap lixx
```

命令只在正常模式且没有有效管理员时可用；拒绝缺失、歧义和非活动账户。初始授权有效一年，操作记录注明本地初始化。已有有效管理员后，后续授权在面板办理。

## 写入与审计

- 所有修改要求有效登录、五分钟内重新验证身份、账户服务可用、CSRF 和正常写入模式。
- 写入事务内重新检查权限、目标账户和版本；最后一位有效管理员不能被撤销或降为成员。
- 每项成功修改与操作记录在同一事务提交；记录包括操作者、对象、时间、变更前后。代表日志查询仅返回有权管理社群的资料变更，不暴露其他授权或举报材料。
- 授权到期、撤销、目标账户不可用时立即停止对应访问。归档或待确认社群不提供代表维护权限。
- 数据库版本升级至 7；现有内容保留。新备份标记版本 7，继续读取版本 6 备份。恢复后清空团队与代表授权，保留审计和内容，防止旧备份复活已撤销的权限。恢复副本默认只读，必须核对授权后由运行人员重新初始化。
