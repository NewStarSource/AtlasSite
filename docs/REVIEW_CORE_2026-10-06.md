## 检查范围与实际限制

已检查新 SQL 的参数绑定与迁移、主要写入权限、版本/防重事务、Goldmark 输出、图片解码与重编码、媒体密钥、导出白名单、来源传播、清单与锚点、恢复模式、通知及任务状态。自动化测试和原始 HTTP 联调覆盖实际成功与失败分支。

没有图形浏览器/手机复现，没有真实域名或 HTTPS，没有真实社群授权、真实用户或外部邮件，没有注册全天监控，也没有连续 30 分钟正式容量测试。未配置 C 工具链，因此没有执行 race。CLI 复核人的身份由本地操作者记录，独立复核组织的真实性需要实际运行安排。私库、密钥、清单和普通快照的离机保护及灾难恢复必须单独验收。

发现高风险问题或恢复结果不确定时继续保持只读/隔离，当前程序仍拒绝 production 模式。
